# Фича "Предыдущий вес и кол-во повторений в hint текстового поля"

## Описание
На экране текущей тренировки есть карточки с текущими записями упражнений. Одна запись упражнения состоит из нескольких записей подходов: "вес" x "количество повторения". Записи подходов появляются по мере заполнения предыдущих. Пример:
```
Жим лежа:
[   ]кг x [     ] повт.

*Заполнили первую строчку* -> 

Жим лежа:
[50 ]кг x [10   ] повт
[   ]кг x [     ] повт.

```

Требуется добавить hint (полупрозрачный текст, видимый если поле ввода пустое) в текстовые поля записей подходов, показывающие значения веса и количества повторений сделанные на последней тренировке с таким упражнением на аналогичном по счету подходе.
Примеры:

```

Прошлая тренировка:

Жим лежа:
50кг x 10
60кг x 7
60кг x 6


Текущая тренировка:

Жим лежа:
[hint:50]кг x [hint:10] повт.

*Заполнили первую строчку* -> 

[50 ]кг x [10   ] повт
[hint:60]кг x [hint:7] повт.
```

## corner cases:
- Если упражнение делается первый раз и нет истории → hint не отображается
- Если нужен hint для n по счету подхода, но на последней тренировке <n подходов → только для n подхода ищем последнюю тренировку на которой было хотя бы n записей подходов, если таковой нет hint не отображается 

## Существующая проблема
- Порядок подходов в упражнении определен не в рамках одного упражнения в тренировке, а по всем подходам всех упражнений в тренировке. Как следствие сложно вычислить порядок подходов в одном упражнении в разных тренировках. Требуется доработка бд под локальный порядок подходов (понять почему так не было с самого начала)
