# Фича "Позиция упражнения в тренировке"

## Описание
В текущей тренировке, в bottom sheet истории упражнения сделать отображение каким по счету было это упражнение в той тренировке

## Сложность
В одном workout порядок упражнений определяется только через подходы сквозным позиционированием, то-есть, чтобы понять какое по счету было упражнение, нужно вычислять из подходов в тренировке
