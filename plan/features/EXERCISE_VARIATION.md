# Вариации в упражнение

## Суть
Я хочу чтобы в упражнение можно было добавить вариации. Пример: упражнение - тяга верхнего блока, вариации: обычный, узкая ручка, широкая ручка.

Эти вариации должны быть доступны:
- при создании и редактировании упражнения
  - в редакторе упражнений в конце над кнопками удалить сохранить должна быть надпись "+ добавить вариацию"
  - При нажатии на эту кнопку прям в этому же редакторе появляется первый элемент списка, редактируемая строка, в которую можно дописать вариацию, вариации сохраняются при сохранении упражнения, текст вариации можно менять  
  - В списке вариаций у элементов должная быть иконка мусорки для удаления, если ее нажать открывается боттом шит с предупреждением, что тогда все упражнения с этой вариацией станут с вариацией "обычный"
- при выборе упражнения в тренировке, и там же можно было бы создать новую вариацию
  - По дефолту вариаций у упражнения нет, чтобы ее выбрать, нужно нажать на название упражнения в текущей тренировке, по нажатию открывается боттом шит с выбором вариаций. 
  - Контент боттом шита выбора вариации должен выглядеть аналогично блоку вариаций при редактировании упражнения, но изменять названия вариаций нельзя, можно только создать новую или выбрать ее по нажатию.
  - После выбора вариации, если выбрана не "обычный", она появляется серым текстом, чуть меньше под названием упражнения.
  - null вариация у упражнения/подхода = "обычный"

## БД
Вариация - это по сути просто строка.
Скорее всего нужно создать новую таблицу в БД с unique uuid по всем вариациям и foreign key к упражнению (поля name, id, exerciseId, unique(name)). В ExerciseSetEntity добавить nullable variationId (foreignKey on delete set null). 

## Статистика
На экране статистки по показателям если у упражнения есть вариация, то у нас появляется дропдаун посередине где можно выбрать вариации чекбоксами, и чекбокс "все"

## Backup
Добавить поддержку вариаций в формат импорта/экспорта. Скорее всего что-то типо "название_упражнения [:: вариация]" если вариации нет остается просто  "название_упражнения" как есть сейчас, если есть вот этот разделитель "::" то добавить вариацию. И так же при импорте искать уже существующие вариации через приведение к lowercase и trim
