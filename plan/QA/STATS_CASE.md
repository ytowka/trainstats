# Проверка статистики

Вход: экран истории → кнопка с `ic_chart`.

## Основной сценарий

1. Сохранить несколько тренировок с одним упражнением и разным количеством подходов.
2. Открыть статистику. Первым выбирается упражнение с сохранённой историей.
3. Открыть список упражнений и найти упражнение по части названия. Поиск не зависит от регистра и закреплён сверху при прокрутке меню. После ввода запроса список результатов возвращается к началу. Выбор показателя оформлен так же, как выбор упражнения: подпись сверху, выбранное значение и стрелка ниже. Обе секции выбора нажимаются по всей площади, включая отступы; меню имеют ширину карточки. При открытии стрелки поворачиваются на 180°, при закрытии возвращаются вниз.
4. Проверить график: X — время тренировки. Первым в переключателе стоит «макс»: по умолчанию показана только эта линия, лучший подход в каждой тренировке по выбранному показателю. Отдельные подходы выключены и включаются независимо. Номера определяются порядком подходов выбранного упражнения внутри тренировки, включая повторные группы этого упражнения.
5. Переключить Y между весом, повторениями и объёмом подхода.
6. По умолчанию показаны последние шесть календарных месяцев истории выбранного упражнения. Масштабировать график двумя пальцами. Переместить по горизонтали жестом или ползунком. Двойное нажатие показывает всю историю. Вертикальный жест одним пальцем от графика прокручивает страницу, включая небольшой наклон; горизонтальный перемещает период и сохраняет это направление до отпускания пальца.
7. Нажать подписи подходов в легенде: соответствующие линии и точки скрываются и возвращаются. Скрытые линии не участвуют в выборе точек кнопками. Точка, совпадающая на нескольких включённых линиях, не дублируется при переходе кнопками. Подписи имеют размер 14sp.
8. Нажать на точку. Под графиком появляется значение подхода и карточка соответствующей тренировки с датой и упражнениями. Подпись показывает весь подход для любого показателя: вес × повторения, для раздельного упражнения — отдельно левую и правую сторону; у упражнения без веса показываются только повторения. Все карточки находятся в прокручиваемом списке.
9. Открыть карточку выбранного подхода нажатием на значение подхода, данные тренировки или отступы: вся объединённая карточка кликабельна и имеет общий ripple. Показаны все упражнения, веса и повторения; полей ввода, сохранения и удаления нет. Значения подходов выровнены по центру, без надписей «Подход N»; числа жирные и на 2sp крупнее единиц измерения.
10. В конце страницы показан рекорд выбранного показателя за всю историю и карточка тренировки с переходом к просмотру. Вся объединённая карточка рекорда кликабельна, включая полный подход и отступы; нажатие открывает тренировку. В блоке рекорда показан полный подход; для объёма дополнительно показано его произведение. Рекорд не зависит от периода и включённых линий; при равном весе выбирается больше повторений, при равных повторениях или объёме — больший вес. При полном совпадении показана первая тренировка. После карточки есть нижний отступ 40dp.
11. Вернуться назад: выбор точки сохраняется. Проверить восстановление экрана после пересоздания Activity.

## Расчёты и особые случаи

- Учитываются неархивные тренировки с подходами, как в истории. Флаг `saved` не используется для отбора: текущий редактор сохраняет записи с `saved=false`.
- Подходы с нулём повторений исключены из всех показателей, максимумов и рекордов. Для раздельного упражнения исключается подход с нулём на обеих сторонах. Номера остальных подходов сохраняются; пустые тренировки не расширяют диапазон графика.
- Порядок упражнений совпадает со списком упражнений: репозиторий ранжирует их по частоте использования.
- Вес — дополнительный вес из записи подхода; собственный вес не учитывается.
- Повторения раздельного упражнения — среднее левой и правой стороны.
- Объём обычного подхода — вес × повторения; раздельного — вес × (лево + право).
- Отсутствующий вес исключает точку из метрик веса и объёма; явно указанный нулевой вес остаётся точкой.
- Если нет упражнений или истории, появляется соответствующее пояснение.
- Для упражнения без веса первоначально выбираются повторения.
- Одна тренировка отображается точками с ненулевым диапазоном времени.
- Тренировки с одинаковым временем сохраняют отдельные идентификаторы.
- Кнопки перехода между точками позволяют выбрать совпадающие точки.
- Ошибка загрузки показывает кнопку повторной попытки.

## Автоматические проверки

- `StatisticsTest` — расчёты максимумов по тренировкам и рекордов за всю историю, календарный диапазон, порядок подходов, фильтрация, выбор упражнения, переключение подходов, состояние после возврата и повторная загрузка после ошибки.
- `StatisticsScreenTest` — поиск, размеры dropdown, метрики, максимум по умолчанию, переключение подходов, рекорд и переход к его тренировке, жесты масштаба, выбор точки, просмотр без записи данных и восстановление навигации.

```sh
./gradlew :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.danilkha.trainstats.StatisticsScreenTest
./gradlew :app:assembleDebug :app:lintDebug :ui-compose:compileKotlinIosSimulatorArm64
```
